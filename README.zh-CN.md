# SamShoAccess

> 本翻译未经母语者校对。如有用词错误，欢迎报告。

**SAMURAI SHODOWN**（侍魂 晓，2019 年，Steam 版）的无障碍 Mod：让游戏可以用你的屏幕阅读器读出来。菜单、选项、角色与场地选择、剧情字幕、教程、指令表、数据库、画廊、联机、结算画面，以及对战中的数值。

你听到的几乎每一个词都是游戏自己的，使用游戏所设置的语言。游戏里没有的少数词语（指令方向、按键名称、"体力"、"怒气"）已翻译成游戏的十一种语言。

作者：**Bruno Broiero**。与 Claude 共同制作。

## 需要

- Steam 版 SAMURAI SHODOWN（Windows）。
- 正在运行的屏幕阅读器：NVDA 或 JAWS。Mod 通过 PRISM 朗读。
- [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS)，虚幻引擎游戏的 Mod 加载器。下载包中已附带可在本游戏上运行的版本（实验版，2026 年 9 月 21 日），无需另外获取。
- XInput（Xbox 类）手柄可选，但 Mod 是围绕手柄设计的。

## 安装

1. 从 Releases 页面下载最新的 `SamShoAccess-x.y.z.zip`。
2. 把其中的全部内容解压到 `SamuraiShodown\Binaries\Win64\`（游戏文件夹；在 Steam 中为 `steamapps\common\SamuraiShodown\SamuraiShodown\Binaries\Win64`）：`dwmapi.dll`、`ue4ss` 文件夹和各语言的 README。
3. **从 Steam** 启动游戏（不要直接运行 .exe：没有 Steam 时游戏会以英文启动且处于离线状态）。
4. 加载完成后 Mod 会说 "SamShoAccess"。如果没听到，按 F8：它会报出找到的屏幕阅读器名称。

## Mod 的按键

| 按键 | 手柄 | 作用 |
|---|---|---|
| F1 | 右摇杆 左或右 | 读出全部保留内容（指令表、表格、结算） |
| F2 / F3 | 右摇杆 上 / 下 | 保留内容的上一项 / 下一项 |
| F10 | 按下右摇杆 | 切换指令记法（普通、街机、街机简化、FGC、FGC 简化）。选择会被保存 |
| F4 | 按下右摇杆（没有保留内容时） | 读出当前画面的按键说明（"9 或 A 确认，0 或 B 返回"） |
| F8 | | 报出 Mod 使用的屏幕阅读器 |
| Ctrl + Esc | | 停止朗读 |

方向键、Enter 和 Backspace 属于游戏，不属于 Mod。

## 对战中

没有任何内容会自动朗读：对战本身已经能听见。用右摇杆询问你需要的数值：

| 右摇杆 | 读出 |
|---|---|
| 左 | 双方体力："体力 71%, 80%"（先是你这一方） |
| 上 | 怒气："怒气 41%, 最大" |
| 下 | 已赢回合："回合 1, 0"。生存、限时、铁人模式中为你的连胜数 |
| 右 | 本回合剩余时间 |
| 按下 | 全部 |

键盘：F2 体力，F3 怒气，F10 回合，F1 全部。

生存、限时和铁人模式只读你这一方。

## 指令表及其记法

在游戏里，一条指令是一排图片：箭头、按钮、一个"加"、条件。Mod 把它们变成文字；由于玩家接触指令表的路径各不相同（街机厅、论坛，或者都不是），Mod 提供五种说法。用 F10 或按下右摇杆切换，选择会被保存。同一条指令（前四分之一圈加重斩）在各记法下：

| 记法 | 读法 |
|---|---|
| 普通 | 下，斜下前，前 加 重斩 |
| 街机 | 前四分之一圈，重斩 |
| 街机简化 | 前四分之一圈，C |
| FGC | 2 3 6，重斩 |
| FGC 简化 | 2 3 6，C |

- **普通**逐个方向用文字读出。最长，也最不预设任何知识。
- **街机**说出形状：四分之一圈、半圈、升龙指令及其反向。这是口头说指令的方式。
- **FGC** 使用数字小键盘的数字，即社区记法：6 是前，2 是下，3 是斜下前；始终以面向右为准。
- **简化**变体把按钮名称换成机台的字母：A 轻斩，B 中斩，C 重斩，D 踢。

朗读是这样设计的，因为图片用形状表达的东西，文字必须说出来：

- 斜向是一次输入，所以称为"斜"："下，斜下前，前"。若读成"下，下 前，前"，就分不清是一次输入还是两次。
- 画在一起的两个按钮要同时按下，所以在所有记法里都用"加"连接。
- 游戏画在招式名周围的条件（"～中"）只说一次，不拆成两半。
- 像"连打"这样的条件放在它所修饰的按钮之后："前 加 轻斩，连打"——按说话的顺序，不按画面的顺序。
- 按钮和条件的名称是游戏自己的词，取自游戏指令表的图例；方向、形状、"加"和"或"是 Mod 的词，有十一种语言。
- 游戏里的"或"有几种形式（两个可选按钮、两条指令、一个列表），全都用同一个词读出。

用右摇杆浏览指令表（上下逐招，左右整表），或用 F2、F3、F1。进入时先读角色和分类（"色，必杀技"），然后每招读作"名称，条件（如有）：指令"，例如"Elysium Halo：前，下，斜下前 加 轻斩 或 中斩 或 重斩"。

## 会读出的内容

- 主菜单和所有子菜单，含每个条目的说明。
- 选项：游戏、画面、声音（音量以 % 表示）、语言与字幕、按键设置（每个动作及其按键或按钮）。
- 角色选择，包括随机、服装与颜色；场地选择；对战中的操作方分配。
- 剧情：字幕与对话、解锁、尾声与制作人员名单。
- 教程：说明、课题与结束语，按键以文字读出。
- 指令表：每个招式及其指令，用你选择的记法；用摇杆或 F2 / F3 逐条浏览。
- 暂停菜单与训练设置。
- 数据库：个人资料、我的排名、综合记录。
- 画廊：影片、插画、语音与音乐，含标签页与翻页。
- 联机：排行榜、排位赛与休闲赛画面、幽灵战的幽灵列表。
- 结算：胜者台词自动读出；分数保留，用摇杆或 F1 询问。
- 解锁提示与通知。

## 不会读出的内容

- 剧情通关后的祝贺画面是一张没有文字的图片。
- 联机房间与聊天未与对手实际测试。
