# SamSho Reader

> 이 번역은 원어민의 검토를 거치지 않았습니다. 잘못된 단어가 있다면 보고할 가치가 있는 버그입니다.

**SAMURAI SHODOWN**(2019, Steam)용 접근성 모드입니다. 게임을 스크린 리더로 읽을 수 있게 합니다. 메뉴, 옵션, 캐릭터와 스테이지 선택, 스토리 자막, 튜토리얼, 커맨드 리스트, 데이터베이스, 갤러리, 온라인, 결과, 그리고 대전 중의 수치까지.

들리는 말은 거의 모두 게임 자체의 말이며, 게임에 설정한 언어로 읽힙니다. 게임에 없는 몇 안 되는 단어(커맨드 방향, 키 이름, "체력", "분노")는 게임의 11개 언어로 번역되어 있습니다.

제작자: **Bruno Broiero**. Claude와 함께 제작.

## 필요한 것

- Steam용 SAMURAI SHODOWN (Windows).
- 실행 중인 스크린 리더: NVDA 또는 JAWS. 모드는 PRISM을 통해 말합니다.
- [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS), Unreal 게임용 모드 로더. 이 게임에서 동작하는 버전(실험 빌드, 2026년 9월 21일)이 다운로드에 포함되어 있습니다. 따로 받을 것은 없습니다.
- XInput(Xbox 방식) 게임패드는 선택 사항이지만, 모드는 패드를 기준으로 설계되었습니다.

## 설치

1. Releases 페이지에서 최신 `SamShoReader-x.y.z.zip`을 내려받습니다.
2. 내용물을 모두 `SamuraiShodown\Binaries\Win64\`에 풉니다(게임 폴더. Steam에서는 `steamapps\common\SamuraiShodown\SamuraiShodown\Binaries\Win64`). `dwmapi.dll`, `ue4ss` 폴더, README 파일들입니다.
3. 게임은 **Steam에서** 실행합니다(.exe로 직접 실행하면 영어로, 오프라인으로 시작됩니다).
4. 로딩이 끝나면 모드가 "SamSho Reader"라고 말합니다. 들리지 않으면 F8을 누르세요. 찾은 스크린 리더의 이름을 말합니다.

## 모드의 키

| 키 | 패드 | 동작 |
|---|---|---|
| F1 | 오른쪽 스틱 왼쪽 또는 오른쪽 | 보관 중인 내용(커맨드 리스트, 표, 결과)을 모두 읽기 |
| F2 / F3 | 오른쪽 스틱 위 / 아래 | 보관 중인 내용의 이전 / 다음 항목 |
| F10 | 오른쪽 스틱 클릭 | 커맨드 표기 변경(일반, 아케이드, 아케이드 간략, FGC, FGC 간략). 선택은 저장됩니다 |
| F4 | 오른쪽 스틱 클릭(보관 중인 것이 없을 때) | 화면의 버튼 안내 읽기("9 또는 A 확인, 0 또는 B 뒤로") |
| F7 | | 음성 멈추기 |
| F6 | L3 + R3 (두 스틱 동시에 클릭) | 모드를 끄고, 같은 조작으로 다시 켭니다. 게임 자체의 켜짐/꺼짐 단어로 확인됩니다. 저장되지 않으며 시작할 때는 항상 켜져 있습니다 |
| F8 | | 모드가 사용하는 스크린 리더 이름 말하기 |
| Ctrl + Esc | | 음성 중단 |

방향키, Enter, Backspace는 게임의 키이며 모드의 키가 아닙니다.

## 대전 중

아무것도 저절로 말하지 않습니다. 대전은 이미 소리로 들리기 때문입니다. 오른쪽 스틱으로 필요한 수치를 물어봅니다.

| 오른쪽 스틱 | 읽는 내용 |
|---|---|
| 왼쪽 | 양쪽의 체력: "체력 71%, 80%" (내 쪽이 먼저) |
| 위 | 분노: "분노 41%, 최대" |
| 아래 | 딴 라운드: "라운드 1, 0". 서바이벌, 타임 어택, 아이언맨에서는 연승 수 |
| 오른쪽 | 라운드의 남은 시간 |
| 클릭 | 모두 |

키보드: F2 체력, F3 분노, F10 라운드, F1 모두.

서바이벌, 타임 어택, 아이언맨에서는 내 쪽만 읽습니다.

## 커맨드 리스트와 표기법

게임에서 커맨드는 그림의 나열입니다. 화살표, 버튼, "플러스", 조건. 모드는 이를 말로 바꾸는데, 플레이어가 커맨드 리스트에 이르는 길은 저마다 다르므로(오락실, 게시판, 혹은 둘 다 아님) 다섯 가지 읽기 방식을 제공합니다. F10 또는 오른쪽 스틱 클릭으로 바꾸며, 선택은 저장됩니다. 같은 커맨드(앞으로 4분의 1 회전 + 강 베기)를 각각 읽으면:

| 표기법 | 읽는 소리 |
|---|---|
| 일반 | 아래, 대각선 아래 앞, 앞 플러스 강 베기 |
| 아케이드 | 앞으로 4분의 1 회전, 강 베기 |
| 아케이드 간략 | 앞으로 4분의 1 회전, C |
| FGC | 2 3 6, 강 베기 |
| FGC 간략 | 2 3 6, C |

- **일반**은 방향 하나하나를 말로 읽습니다. 가장 길고, 아무것도 전제하지 않습니다.
- **아케이드**는 모양의 이름을 말합니다. 4분의 1 회전, 반회전, 승룡권 커맨드, 그리고 각각의 역방향. 커맨드를 입으로 말할 때의 방식입니다.
- **FGC**는 숫자 키패드의 숫자, 커뮤니티의 표기법입니다. 6이 앞, 2가 아래, 3이 대각선 아래 앞. 항상 오른쪽을 보는 기준입니다.
- **간략** 변형은 버튼 이름을 캐비닛의 글자로 바꿉니다. A 약 베기, B 중 베기, C 강 베기, D 발차기.

읽기를 어떻게 설계했는지. 그림은 모양으로 전하는 것을 말은 소리 내어 전해야 하기 때문입니다.

- 대각선은 하나의 입력이므로 "대각선"이라고 부릅니다. "아래, 대각선 아래 앞, 앞". "아래, 아래 앞, 앞"이라고 하면 입력이 하나인지 둘인지 알 수 없습니다.
- 붙여 그려진 두 버튼은 동시에 누르는 것이므로, 모든 표기법에서 "플러스"로 잇습니다.
- 게임이 기술 이름 둘레에 그리는 조건("~ 중")은 두 조각이 아니라 한 번만 말합니다.
- "연타" 같은 조건은 그것이 적용되는 버튼 뒤에 말합니다. "앞 플러스 약 베기, 연타". 그려진 순서가 아니라 말하는 순서입니다.
- 버튼과 조건의 이름은 게임의 말로, 게임 자체 커맨드 리스트의 범례에서 가져옵니다. 방향, 모양, "플러스"와 "또는"은 모드의 말이며 11개 언어로 있습니다.
- "또는"은 게임 안에서 여러 형태로 나타나지만(두 버튼 중 하나, 두 커맨드, 목록) 모두 같은 말로 읽습니다.

리스트는 오른쪽 스틱(위아래로 기술 하나씩, 좌우로 전체) 또는 F2, F3, F1로 읽어 나갑니다. 들어가면 격투가와 분류("시키, 필살기")를 말하고, 이어서 각 기술을 "이름, 조건이 있으면 조건: 커맨드" 형태로 읽습니다. 예: "Elysium Halo: 앞, 아래, 대각선 아래 앞 플러스 약 베기 또는 중 베기 또는 강 베기".

## 읽어 주는 것

- 메인 메뉴와 모든 하위 메뉴(각 항목의 설명 포함).
- 옵션: 게임, 화면, 사운드(볼륨은 %), 언어와 자막, 버튼 설정(각 동작과 그 키 또는 버튼).
- 캐릭터 선택(랜덤, 코스튬, 색상 포함), 스테이지 선택, 대전의 조작 측 지정.
- 스토리: 자막과 대화, 해금, 에필로그, 크레딧.
- 튜토리얼: 설명, 과제, 마무리 메시지(키는 말로).
- 커맨드 리스트: 각 기술과 선택한 표기의 커맨드. 스틱 또는 F2 / F3로 차례로 읽기.
- 일시 정지 메뉴와 트레이닝 설정.
- 데이터베이스: 프로필, 내 랭킹, 종합 기록.
- 갤러리: 영상, 아트워크, 음성, 음악(탭과 페이지 포함).
- 온라인: 리더보드, 랭크 매치와 캐주얼 매치 화면, 고스트 매치의 고스트 목록.
- 결과: 승자의 대사는 저절로 읽힙니다. 점수는 보관되어 스틱 또는 F1로 들을 수 있습니다.
- 해금 알림과 공지.

## 읽어 주지 않는 것

- 스토리를 끝냈을 때의 축하 화면은 글자 없는 그림입니다.
- 온라인 방과 채팅은 상대와 함께 시험하지 않았습니다.

## 언어

모드는 게임의 언어로 말합니다. 모드 고유의 단어는 스페인어에서만 귀로 확인했고, 다른 언어에서는 화자의 검토 없이 번역되었습니다. 잘못된 단어는 보고할 가치가 있는 버그입니다.

## 참고

- 모드는 게임 파일을 전혀 수정하지 않습니다.
- UE4SS는 RE-UE4SS 팀의 것으로 MIT 라이선스이며, `prism.dll`과 `tolk.dll`은 [PRISM](https://github.com/ethindp/prism)의 것으로 MPL 2.0입니다. `THIRD-PARTY.md`를 보세요.
- 제거하려면 `dwmapi.dll`과 `ue4ss` 폴더를 삭제합니다.
- 모드의 소스 코드는 아직 공개하지 않았습니다. 사용이 안정되면 공개할 예정입니다. 다운로드는 자유롭게 사용할 수 있습니다.
