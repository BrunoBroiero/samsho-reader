# SamSho Reader

[English](README.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Italiano](README.it.md) ·

**SAMURAI SHODOWN**(2019, Steam, PC)용 스크린 리더 모드입니다. 메뉴, 스토리, 커맨드 리스트, 표, 화면의 글을 이미 쓰고 있는 스크린 리더(NVDA, JAWS)로, 게임이 실행 중인 언어 그대로 읽어 줍니다.

제작: Bruno Broiero, Claude의 도움으로.

## 하는 일

- 메인 메뉴와 모든 하위 메뉴(각 항목의 설명 포함).
- 옵션: 게임, 화면, 사운드(볼륨은 %), 언어와 자막, 버튼 설정(각 동작과 그 키 또는 버튼).
- 캐릭터 선택(랜덤, 코스튬, 색상 포함), 스테이지 선택, 대전의 조작 측 지정.
- 스토리: 자막과 대화, 해금, 에필로그, 크레딧.
- 튜토리얼: 설명, 과제, 마무리 메시지(키는 말로).
- 커맨드 리스트: 각 기술과 선택한 표기의 커맨드. 스틱 또는 F2 / F3로 차례로 읽기.
- 일시 정지 메뉴와 트레이닝 설정.
- 데이터베이스: 프로필, 내 랭킹, 종합 기록.
- 갤러리: 영상, 아트워크, 음성, 음악(탭과 페이지 포함).
- 온라인: 리더보드, 랭크 매치와 캐주얼 매치 화면, 고스트 매치의 고스트 목록.
- 결과: 승자의 대사는 저절로 읽힙니다. 점수는 보관되어 스틱 또는 F1로 들을 수 있습니다.
- 해금 알림과 공지.

읽지 않는 것:

- 스토리를 끝냈을 때의 축하 화면은 글자 없는 그림입니다.
- 온라인 방과 채팅은 상대와 함께 시험하지 않았습니다.

## 설치

Steam PC판 SAMURAI SHODOWN, Windows x64, 실행 중인 스크린 리더(NVDA 또는 JAWS)가 필요합니다. Unreal 게임용 모드 로더 UE4SS는 이 게임에서 동작하는 버전이 zip에 들어 있습니다.

zip의 내용물을 모두 `SamuraiShodown\Binaries\Win64`에 풉니다(Steam에서는 `steamapps\common\SamuraiShodown\SamuraiShodown\Binaries\Win64`). `dwmapi.dll`, `ue4ss` 폴더, 그리고 이 README 파일들입니다.

게임은 .exe가 아니라 Steam에서 실행하세요. Steam 없이는 영어로, 오프라인으로 시작됩니다. 모드가 동작하면 바로 "SamSho Reader"라고 말합니다. 들리지 않으면 F8이 찾은 스크린 리더의 이름을 말합니다. 게임 파일은 전혀 수정되지 않습니다.

제거하려면 `dwmapi.dll`과 `ue4ss` 폴더를 삭제합니다. UE4SS와, 스크린 리더에 말을 전하는 라이브러리 PRISM은 각자의 라이선스로 배포됩니다. `THIRD-PARTY.md`를 보세요.

## 키

대전 밖에서:

| 키 | 패드 | 동작 |
|---|---|---|
| F1 | 오른쪽 스틱 왼쪽 또는 오른쪽 | 보관 중인 내용(커맨드 리스트, 표, 결과)을 모두 읽기 |
| F2 / F3 | 오른쪽 스틱 위 / 아래 | 보관 중인 내용의 이전 / 다음 항목 |
| F10 | 오른쪽 스틱 클릭 | 커맨드 표기 변경(일반, 아케이드, 아케이드 간략, FGC, FGC 간략). 선택은 저장됩니다 |
| F4 | 오른쪽 스틱 클릭(보관 중인 것이 없을 때) | 화면의 버튼 안내 읽기("9 또는 A 확인, 0 또는 B 뒤로") |

대전 중:

아무것도 저절로 말하지 않습니다. 대전은 이미 소리로 들리기 때문입니다. 오른쪽 스틱으로 필요한 수치를 물어봅니다.

| 오른쪽 스틱 | 읽는 내용 |
|---|---|
| 왼쪽 | 양쪽의 체력: "체력 71%, 80%" (내 쪽이 먼저) |
| 위 | 분노: "분노 41%, 최대" |
| 아래 | 딴 라운드: "라운드 1, 0". 서바이벌, 타임 어택, 아이언맨에서는 연승 수 |
| 오른쪽 | 라운드의 남은 시간 |
| 클릭 | 모두 |

키보드: F2 체력, F3 분노, F10 라운드, F1 모두.

서바이벌, 타임 어택, 아이언맨에서는 내 쪽만 읽습니다.

항상:

| 키 | 패드 | 동작 |
|---|---|---|
| F6 | L3 + R3 (두 스틱 동시에 클릭) | 모드를 끄고, 같은 조작으로 다시 켭니다. 게임 자체의 켜짐/꺼짐 단어로 확인됩니다. 저장되지 않으며 시작할 때는 항상 켜져 있습니다 |
| F8 | | 모드가 사용하는 스크린 리더 이름 말하기 |

## F1, F2, F3과 오른쪽 스틱이 읽는 것

많은 화면에는 커서 아래에 있는 것보다 더 많은 내용이 있습니다. 커맨드 리스트, 결과의 점수, 기록 표, 레슨 같은 것들입니다. 모드는 도착하자마자 그 모두를 읽지 않습니다. 보관해 두었다가 이 키로 건넵니다. F3은 다음 항목, F2는 이전 항목, F1은 전부 한 번에. 끝에 이르면 F3은 아무 말도 하지 않습니다. 더 없다는 뜻입니다. 패드에서는 오른쪽 스틱이 같은 일을 합니다. 아래가 F3, 위가 F2, 왼쪽이나 오른쪽이 F1입니다.

항목이 무엇인지는 화면에 따라 다릅니다.

- **커맨드 리스트**: 각 기술과 그 커맨드를 F10이나 스틱 클릭으로 고른 표기로 읽습니다. 표기를 바꾸면 새 표기로 기술을 다시 말합니다. 들어가면 격투가와 분류를 말합니다.
- **튜토리얼**: 설명과 과제의 각 문장. 입력은 말로 읽히고, 클릭은 그 표기도 바꿉니다.
- **결과**(대전 후): 승자의 대사는 저절로 읽힙니다. 점수는 일부러 키 안에서 기다립니다. 대사가 숫자에 묻히지 않도록입니다.
- **대전 결과**: 각 쪽의 승, 패, 무승부, 승률, 포인트.
- **플레이어 데이터**: 기록과 랭킹 표. 한 줄이 한 항목입니다. 도착하면 제목과 첫 줄을 말합니다.
- **버튼 안내**: 보관 중인 것이 없을 때 스틱 클릭(또는 F4)은 화면 자체의 버튼 안내를 읽습니다.

## 커맨드 리스트와 표기법

게임에서 커맨드는 그림의 나열입니다. 화살표, 버튼, "플러스", 조건. 모드는 이를 말로 바꾸는데, 플레이어가 커맨드 리스트에 이르는 길은 저마다 다르므로(오락실, 게시판, 혹은 둘 다 아님) 다섯 가지 읽기 방식을 제공합니다. F10 또는 오른쪽 스틱 클릭으로 바꾸며, 선택은 저장됩니다. 같은 커맨드(앞으로 4분의 1 회전 + 강 베기)를 각각 읽으면:

| 표기법 | 읽는 소리 |
|---|---|
| 일반 | 아래, 대각선 아래 앞, 앞 플러스 강 베기 |
| 아케이드 | 앞으로 4분의 1 회전, 강 베기 |
| 아케이드 간략 | 앞으로 4분의 1 회전, C |
| FGC | 2 3 6, 강 베기 |
| FGC 간략 | 2 3 6, C |

- **일반**은 방향 하나하나를 말로 읽습니다. 가장 길고, 아무것도 전제하지 않습니다.
- **아케이드**는 모양의 이름을 말합니다. 4분의 1 회전, 반회전, 승룡권 커맨드, 그리고 각각의 역방향. 커맨드를 입으로 말할 때의 방식입니다.
- **FGC**는 숫자 키패드의 숫자, 커뮤니티의 표기법입니다. 6이 앞, 2가 아래, 3이 대각선 아래 앞. 항상 오른쪽을 보는 기준입니다.
- **간략** 변형은 버튼 이름을 캐비닛의 글자로 바꿉니다. A 약 베기, B 중 베기, C 강 베기, D 발차기.

읽기를 어떻게 설계했는지. 그림은 모양으로 전하는 것을 말은 소리 내어 전해야 하기 때문입니다.

- 대각선은 하나의 입력이므로 "대각선"이라고 부릅니다. "아래, 대각선 아래 앞, 앞". "아래, 아래 앞, 앞"이라고 하면 입력이 하나인지 둘인지 알 수 없습니다.
- 붙여 그려진 두 버튼은 동시에 누르는 것이므로, 모든 표기법에서 "플러스"로 잇습니다.
- 게임이 기술 이름 둘레에 그리는 조건("~ 중")은 두 조각이 아니라 한 번만 말합니다.
- "연타" 같은 조건은 그것이 적용되는 버튼 뒤에 말합니다. "앞 플러스 약 베기, 연타". 그려진 순서가 아니라 말하는 순서입니다.
- 버튼과 조건의 이름은 게임의 말로, 게임 자체 커맨드 리스트의 범례에서 가져옵니다. 방향, 모양, "플러스"와 "또는"은 모드의 말이며 11개 언어로 있습니다.
- "또는"은 게임 안에서 여러 형태로 나타나지만(두 버튼 중 하나, 두 커맨드, 목록) 모두 같은 말로 읽습니다.

리스트는 오른쪽 스틱(위아래로 기술 하나씩, 좌우로 전체) 또는 F2, F3, F1로 읽어 나갑니다. 들어가면 격투가와 분류("시키, 필살기")를 말하고, 이어서 각 기술을 "이름, 조건이 있으면 조건: 커맨드" 형태로 읽습니다. 예: "Elysium Halo: 앞, 아래, 대각선 아래 앞 플러스 약 베기 또는 중 베기 또는 강 베기".

## 문제 보고

게임을 정상적으로 종료하고 `SamuraiShodown\Binaries\Win64\ue4ss\UE4SS.log`를 보내 주세요. 게임이 표시한 것과 모드가 그에 대해 말한 것이 정확한 문구 그대로 기록되어 있으므로, 들은 내용을 적어 둘 필요가 없습니다. 어떤 화면이었는지, 무엇이 들려야 했는지를 알려 주세요.

## 빌드

모드는 UE4SS가 불러오는 Lua입니다. 컴파일하는 것은 `prism_bridge.dll`뿐으로, 음성을 PRISM에 넘기고 패드를 읽는 작은 네이티브 모듈입니다(`native\prism_bridge\build.ps1`, MSVC 필요). `python tools\package.py`가 게임 폴더에서 릴리스 zip을 만듭니다.

## 번역에 대하여

이 README는 게임이 지원하는 모든 언어로 나옵니다. 화자의 검토를 거친 것은 영어판과 스페인어판뿐입니다. 나머지에 대한 수정은 환영합니다. 모드 자체는 게임의 언어로 말합니다. 말하는 것의 거의 전부가 게임 자체의 글이고, 모드 고유의 몇 안 되는 단어(방향, 키 이름, "체력", "분노")는 스페인어에서만 귀로 확인했습니다.
