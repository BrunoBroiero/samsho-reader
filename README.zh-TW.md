# SamShoAccess

> 本翻譯未經母語者校對。如有用詞錯誤，歡迎回報。

**SAMURAI SHODOWN**（侍魂 曉，2019 年，Steam 版）的無障礙 Mod：讓遊戲可以用你的螢幕閱讀器讀出來。選單、選項、角色與場地選擇、劇情字幕、教學、指令表、資料庫、畫廊、線上、結算畫面，以及對戰中的數值。

你聽到的幾乎每一個詞都是遊戲自己的，使用遊戲所設定的語言。遊戲裡沒有的少數詞語（指令方向、按鍵名稱、「體力」、「怒氣」）已翻譯成遊戲的十一種語言。

作者：**Bruno Broiero**。與 Claude 共同製作。

## 需求

- Steam 版 SAMURAI SHODOWN（Windows）。
- 執行中的螢幕閱讀器：NVDA 或 JAWS。Mod 透過 PRISM 朗讀。
- [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS)，虛幻引擎遊戲的 Mod 載入器。下載包中已附帶可在本遊戲上運作的版本（實驗版，2026 年 9 月 21 日），無需另外取得。
- XInput（Xbox 類）手把為選用，但 Mod 是以手把為中心設計的。

## 安裝

1. 從 Releases 頁面下載最新的 `SamShoAccess-x.y.z.zip`。
2. 把其中的全部內容解壓縮到 `SamuraiShodown\Binaries\Win64\`（遊戲資料夾；在 Steam 中為 `steamapps\common\SamuraiShodown\SamuraiShodown\Binaries\Win64`）：`dwmapi.dll`、`ue4ss` 資料夾和各語言的 README。
3. **從 Steam** 啟動遊戲（不要直接執行 .exe：沒有 Steam 時遊戲會以英文啟動且處於離線狀態）。
4. 載入完成後 Mod 會說「SamShoAccess」。如果沒聽到，按 F8：它會報出找到的螢幕閱讀器名稱。

## Mod 的按鍵

| 按鍵 | 手把 | 作用 |
|---|---|---|
| F1 | 右搖桿 左或右 | 讀出全部保留內容（指令表、表格、結算） |
| F2 / F3 | 右搖桿 上 / 下 | 保留內容的上一項 / 下一項 |
| F10 | 按下右搖桿 | 切換指令記法（一般、大型電玩、大型電玩簡化、FGC、FGC 簡化）。選擇會被儲存 |
| F4 | 按下右搖桿（沒有保留內容時） | 讀出目前畫面的按鍵說明（「9 或 A 確認，0 或 B 返回」） |
| F8 | | 報出 Mod 使用的螢幕閱讀器 |
| Ctrl + Esc | | 停止朗讀 |

方向鍵、Enter 和 Backspace 屬於遊戲，不屬於 Mod。

## 對戰中

沒有任何內容會自動朗讀：對戰本身已經聽得見。用右搖桿詢問你需要的數值：

| 右搖桿 | 讀出 |
|---|---|
| 左 | 雙方體力：「體力 71%, 80%」（先是你這一方） |
| 上 | 怒氣：「怒氣 41%, 最大」 |
| 下 | 已贏回合：「回合 1, 0」。生存、限時、鐵人模式中為你的連勝數 |
| 右 | 本回合剩餘時間 |
| 按下 | 全部 |

鍵盤：F2 體力，F3 怒氣，F10 回合，F1 全部。

生存、限時與鐵人模式只讀你這一方。

## 指令表及其記法

在遊戲裡，一條指令是一排圖片：箭頭、按鈕、一個「加」、條件。Mod 把它們變成文字；由於玩家接觸指令表的途徑各不相同（大型電玩、論壇，或者都不是），Mod 提供五種說法。用 F10 或按下右搖桿切換，選擇會被儲存。同一條指令（前四分之一圈加重斬）在各記法下：

| 記法 | 讀法 |
|---|---|
| 一般 | 下，斜下前，前 加 重斬 |
| 大型電玩 | 前四分之一圈，重斬 |
| 大型電玩簡化 | 前四分之一圈，C |
| FGC | 2 3 6，重斬 |
| FGC 簡化 | 2 3 6，C |

- **一般**逐個方向用文字讀出。最長，也最不預設任何知識。
- **大型電玩**說出形狀：四分之一圈、半圈、昇龍指令及其反向。這是口頭說指令的方式。
- **FGC** 使用數字鍵盤的數字，即社群記法：6 是前，2 是下，3 是斜下前；始終以面向右為準。
- **簡化**變體把按鈕名稱換成機台的字母：A 輕斬，B 中斬，C 重斬，D 踢。

朗讀是這樣設計的，因為圖片用形狀表達的東西，文字必須說出來：

- 斜向是一次輸入，所以稱為「斜」：「下，斜下前，前」。若讀成「下，下 前，前」，就分不清是一次輸入還是兩次。
- 畫在一起的兩個按鈕要同時按下，所以在所有記法裡都用「加」連接。
- 遊戲畫在招式名周圍的條件（「～中」）只說一次，不拆成兩半。
- 像「連打」這樣的條件放在它所修飾的按鈕之後：「前 加 輕斬，連打」——按說話的順序，不按畫面的順序。
- 按鈕和條件的名稱是遊戲自己的詞，取自遊戲指令表的圖例；方向、形狀、「加」和「或」是 Mod 的詞，有十一種語言。
- 遊戲裡的「或」有幾種形式（兩個可選按鈕、兩條指令、一個列表），全都用同一個詞讀出。

用右搖桿瀏覽指令表（上下逐招，左右整表），或用 F2、F3、F1。進入時先讀角色和分類（「色，必殺技」），然後每招讀作「名稱，條件（如有）：指令」，例如「Elysium Halo：前，下，斜下前 加 輕斬 或 中斬 或 重斬」。

## 會讀出的內容

- 主選單和所有子選單，含每個項目的說明。
- 選項：遊戲、畫面、聲音（音量以 % 表示）、語言與字幕、按鍵設定（每個動作及其按鍵或按鈕）。
- 角色選擇，包括隨機、服裝與顏色；場地選擇；對戰中的操作方分配。
- 劇情：字幕與對話、解鎖、尾聲與製作人員名單。
- 教學：說明、課題與結束語，按鍵以文字讀出。
- 指令表：每個招式及其指令，用你選擇的記法；用搖桿或 F2 / F3 逐條瀏覽。
- 暫停選單與訓練設定。
- 資料庫：個人資料、我的排名、綜合紀錄。
- 畫廊：影片、插畫、語音與音樂，含分頁標籤與翻頁。
- 線上：排行榜、排位賽與休閒賽畫面、幽靈戰的幽靈列表。
- 結算：勝者台詞自動讀出；分數保留，用搖桿或 F1 詢問。
- 解鎖提示與通知。

## 不會讀出的內容

- 劇情破關後的祝賀畫面是一張沒有文字的圖片。
- 線上房間與聊天未與對手實際測試。
