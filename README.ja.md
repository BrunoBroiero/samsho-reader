**SAMURAI SHODOWN**（2019年、Steam、PC）向けのスクリーンリーダーMOD。メニュー、ストーリー、コマンドリスト、表、画面上のテキストを、いつも使っているスクリーンリーダー（NVDA、JAWS）で、ゲームの言語のまま読み上げます。

作者: Bruno Broiero。Claudeの協力で制作。

## できること

- メインメニューとすべてのサブメニュー（各項目の説明つき）。
- オプション: ゲーム、画面、サウンド（音量は%）、言語と字幕、ボタンコンフィグ（各操作とそのキーまたはボタン）。
- キャラクター選択（ランダム、コスチューム、カラーを含む）、ステージ選択、対戦での操作側の割り当て。
- ストーリー: 字幕と会話、開放、エピローグ、スタッフロール。
- チュートリアル: 説明、課題、終了メッセージ（キーは言葉で）。
- コマンドリスト: 各技とそのコマンド（選んだ表記で）。スティックまたは F2 / F3 で順に読めます。
- ポーズメニューとトレーニング設定。
- データベース: プロフィール、マイランキング、総合記録。
- ギャラリー: ムービー、アートワーク、ボイス、ミュージック（タブとページを含む）。
- オンライン: リーダーボード、ランクマッチ・カジュアルマッチの画面、ゴーストマッチのゴースト一覧。
- リザルト: 勝者のセリフは自動で読まれます。スコアは保持され、スティックまたは F1 で聞けます。
- 開放のお知らせと通知。

読まれないもの:

- ストーリークリア後の祝福画面は文字のない絵です。
- オンラインのルームとチャットは対戦相手ありで試していません。

## インストール

Steam版 SAMURAI SHODOWN（PC）、Windows x64、起動中のスクリーンリーダー（NVDA または JAWS）が必要です。Unreal製ゲーム用MODローダーの UE4SS は、このゲームで動く版が zip に同梱されています。

zip の中身をすべて `SamuraiShodown\Binaries\Win64` に展開します（Steamでは `steamapps\common\SamuraiShodown\SamuraiShodown\Binaries\Win64`）。`dwmapi.dll`、`ue4ss` フォルダー、そしてこれらの README です。

ゲームは .exe からではなく Steam から起動してください。Steam なしでは英語・オフラインで始まります。動き出すとすぐ MOD が「SamSho Reader」と言います。聞こえない場合は F8 が見つけたスクリーンリーダーの名前を言います。ゲームのファイルは一切変更されません。

アンインストールするには `dwmapi.dll` と `ue4ss` フォルダーを削除します。UE4SS と、スクリーンリーダーに話しかけるライブラリ PRISM は、それぞれのライセンスで配布されています。`THIRD-PARTY.md` を参照してください。

## キー

対戦の外で:

| キー | パッド | 動作 |
|---|---|---|
| F1 | 右スティック 左または右 | 保持している内容（コマンドリスト、表、リザルト）をすべて読む |
| F2 / F3 | 右スティック 上 / 下 | 保持している内容の前 / 次の項目 |
| F10 | 右スティック押し込み | コマンド表記を切り替える（ノーマル、アーケード、アーケード簡易、FGC、FGC簡易）。選択は保存されます |
| F4 | 右スティック押し込み（何も保持していないとき） | 画面のボタン説明を読む（「9 または A 決定、0 または B 戻る」） |

対戦中:

何も自動では話しません。対戦は音で分かるからです。右スティックで必要な数値を尋ねます。

| 右スティック | 読み上げ |
|---|---|
| 左 | 両者の体力: 「体力 71%, 80%」（自分の側が先） |
| 上 | 怒り: 「怒り 41%, 爆発」 |
| 下 | 取ったラウンド: 「ラウンド数 1, 0」。サバイバル、タイムアタック、アイアンマンでは連勝数 |
| 右 | ラウンドの残り時間 |
| 押し込み | すべて |

キーボード: F2 体力、F3 怒り、F10 ラウンド、F1 すべて。

サバイバル、タイムアタック、アイアンマンでは自分の側だけを読みます。

常に:

| キー | パッド | 動作 |
|---|---|---|
| F6 | L3 + R3（両スティック同時押し込み） | MODをオフにし、同じ操作でオンに戻す。ゲーム自身のオン／オフの言葉で確認される。保存されず、起動時は常にオン |
| F8 | | MODが使っているスクリーンリーダーを言う |

## F1、F2、F3 と右スティックが読むもの

多くの画面には、カーソルの下にあるもの以上の内容があります。コマンドリスト、リザルトのスコア、記録の表、レッスンなどです。MODはそれらを到着時にすべて読むのではなく、保持しておき、次のキーで渡します。F3 で次の項目、F2 で前の項目、F1 で全部を一度に。最後まで来ると F3 は何も言いません。それがもう無いという合図です。パッドでは右スティックが同じ働きをします。下が F3、上が F2、左か右が F1 です。

項目が何かは画面によって変わります。

- **コマンドリスト**: 各技とそのコマンド。F10 またはスティック押し込みで選んだ表記で読み、切り替えると新しい表記で技を言い直します。入ると格闘家とカテゴリーを言います。
- **チュートリアル**: 説明と課題の各文。入力は言葉にして読み、押し込みで表記も切り替わります。
- **リザルト**（対戦後）: 勝者のセリフは自動で読まれます。スコアはあえてキーの中で待ちます。セリフが数字に埋もれないためです。
- **対戦リザルト**: 各側の勝ち、負け、引き分け、勝率、ポイント。
- **プレイヤーデータ**: 記録とランキングの表。一行が一項目です。到着時にはタイトルと最初の行を言います。
- **ボタンの凡例**: 何も保持していないとき、スティック押し込み（または F4）は画面自身のボタン凡例を読みます。

## コマンドリストとその表記

ゲームの中でコマンドは絵の列です。矢印、ボタン、「プラス」、条件。MODはそれを言葉にしますが、プレイヤーがコマンドリストにたどり着く道はさまざま（ゲームセンター、掲示板、あるいはどちらでもない）なので、5通りの読み方を用意しています。F10 または右スティック押し込みで切り替え、選択は保存されます。同じコマンド（前に四分の一回転＋強斬り）をそれぞれで読むと:

| 表記 | 読み上げ |
|---|---|
| ノーマル | 下、斜め下前、前 プラス 強斬り |
| アーケード | 前に四分の一回転、強斬り |
| アーケード簡易 | 前に四分の一回転、C |
| FGC | 2 3 6、強斬り |
| FGC簡易 | 2 3 6、C |

- **ノーマル** は方向をひとつずつ言葉で言います。いちばん長く、何も前提にしません。
- **アーケード** は形の名前で言います。四分の一回転、半回転、昇龍コマンド、それぞれの逆。口頭でコマンドを伝えるときの言い方です。
- **FGC** はテンキーの数字、コミュニティの表記です。6 が前、2 が下、3 が斜め下前。常に右向きとして数えます。
- **簡易** の2種はボタン名を筐体の文字に置き換えます。A 弱斬り、B 中斬り、C 強斬り、D 蹴り。

読み上げをどう設計したか。絵は形で伝えることを、言葉は声に出して伝えなければならないからです。

- 斜めは1つの入力なので「斜め」と言います。「下、斜め下前、前」。「下、下 前、前」と言うと、入力が1つか2つか分かりません。
- くっついて描かれた2つのボタンは同時押しなので、どの表記でも「プラス」でつなぎます。
- 技名の周りに描かれる条件（「〜中」）は、二つに割らずに一度だけ言います。
- 「連打」のような条件は、それがかかるボタンの後に言います。「前 プラス 弱斬り、連打」。描かれた順ではなく、話す順です。
- ボタンと条件の名前はゲームの言葉で、ゲーム自身のコマンドリストの凡例から取っています。方向、形、「プラス」「または」はMODの言葉で、11言語分あります。
- 「または」はゲームの中でいくつかの形（2つのボタンのどちらか、2つのコマンド、一覧）で現れますが、すべて同じ言葉で言います。

リストは右スティック（上下で技ごと、左右で全部）または F2、F3、F1 で読み進めます。入ると格闘家とカテゴリー（「シキ、必殺技」）を言い、続けて各技を「技名、条件があれば条件: コマンド」の形で読みます。例:「Elysium Halo: 前、下、斜め下前 プラス 弱斬り または 中斬り または 強斬り」。

## 問題の報告

ゲームを普通に終了し、`SamuraiShodown\Binaries\Win64\ue4ss\UE4SS.log` を送ってください。ゲームが表示したものと、それについてMODが言ったことが、そのままの言葉で記録されています。聞こえた内容を書き留める必要はありません。どの画面だったか、何が聞こえるはずだったかを添えてください。

## ビルド

MODは UE4SS が読み込む Lua です。コンパイルするのは `prism_bridge.dll` だけで、これは音声を PRISM に渡しパッドを読む小さなネイティブモジュールです（`native\prism_bridge\build.ps1`、MSVC が必要）。`python tools\package.py` がゲームフォルダーからリリース用 zip を作ります。

## 翻訳について

この README はゲームが対応するすべての言語で公開されています。話者による確認を受けたのは英語版とスペイン語版だけです。他の言語への訂正を歓迎します。MOD自体はゲームの言語で話します。言うことのほとんどはゲーム自身のテキストで、MOD独自のわずかな言葉（方向、キー名、「体力」「怒り」）はスペイン語でのみ耳で確認しています。
