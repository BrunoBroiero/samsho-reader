# SamSho Reader

> この翻訳はネイティブスピーカーによる確認を受けていません。誤った言葉があれば、報告する価値のあるバグです。

**SAMURAI SHODOWN**（2019年、Steam版）向けのアクセシビリティMODです。ゲームをスクリーンリーダーで読めるようにします。メニュー、オプション、キャラクター・ステージ選択、ストーリーの字幕、チュートリアル、コマンドリスト、データベース、ギャラリー、オンライン、リザルト、そして対戦中の数値まで。

聞こえる言葉のほとんどは、ゲーム自身の言葉で、ゲームに設定した言語で読み上げられます。ゲームに存在しないわずかな言葉（コマンドの方向、キーの名前、「体力」「怒り」）は、ゲームの11言語に翻訳されています。

作者: **Bruno Broiero**。Claudeと共同で制作。

## 必要なもの

- Steam版 SAMURAI SHODOWN（Windows）。
- 起動中のスクリーンリーダー: NVDA または JAWS。MODは PRISM を通して話します。
- [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS)、Unreal製ゲーム用MODローダー。このゲームで動く版（実験版、2026年9月21日）がダウンロードに同梱されています。別途入手するものはありません。
- XInput（Xbox系）ゲームパッドは任意ですが、MODはパッドを前提に設計されています。

## インストール

1. Releases ページから最新の `SamShoReader-x.y.z.zip` をダウンロードします。
2. 中身をすべて `SamuraiShodown\Binaries\Win64\` に展開します（ゲームフォルダー。Steamでは `steamapps\common\SamuraiShodown\SamuraiShodown\Binaries\Win64`）。`dwmapi.dll`、`ue4ss` フォルダー、README です。
3. ゲームは **Steamから** 起動します（.exe から直接起動すると英語・オフラインになります）。
4. 読み込みが終わるとMODが「SamSho Reader」と言います。聞こえない場合は F8 を押してください。見つかったスクリーンリーダーの名前を言います。

## MODのキー

| キー | パッド | 動作 |
|---|---|---|
| F1 | 右スティック 左または右 | 保持している内容（コマンドリスト、表、リザルト）をすべて読む |
| F2 / F3 | 右スティック 上 / 下 | 保持している内容の前 / 次の項目 |
| F10 | 右スティック押し込み | コマンド表記を切り替える（ノーマル、アーケード、アーケード簡易、FGC、FGC簡易）。選択は保存されます |
| F4 | 右スティック押し込み（何も保持していないとき） | 画面のボタン説明を読む（「9 または A 決定、0 または B 戻る」） |
| F7 | | 読み上げを止める |
| F6 | L3 + R3（両スティック同時押し込み） | MODをオフにし、同じ操作でオンに戻す。ゲーム自身のオン／オフの言葉で確認される。保存されず、起動時は常にオン |
| F8 | | MODが使っているスクリーンリーダーを言う |
| Ctrl + Esc | | 読み上げを止める |

矢印キー、Enter、Backspace はゲームのキーであり、MODのものではありません。

## 対戦中

何も自動では話しません。対戦は音で分かるからです。右スティックで必要な数値を尋ねます。

| 右スティック | 読み上げ |
|---|---|
| 左 | 両者の体力: 「体力 71%, 80%」（自分の側が先） |
| 上 | 怒り: 「怒り 41%, 爆発」 |
| 下 | 取ったラウンド: 「ラウンド数 1, 0」。サバイバル、タイムアタック、アイアンマンでは連勝数 |
| 右 | ラウンドの残り時間 |
| 押し込み | すべて |

キーボード: F2 体力、F3 怒り、F10 ラウンド、F1 すべて。

サバイバル、タイムアタック、アイアンマンでは自分の側だけを読みます。

## コマンドリストとその表記

ゲームの中でコマンドは絵の列です。矢印、ボタン、「プラス」、条件。MODはそれを言葉にしますが、プレイヤーがコマンドリストにたどり着く道はさまざま（ゲームセンター、掲示板、あるいはどちらでもない）なので、5通りの読み方を用意しています。F10 または右スティック押し込みで切り替え、選択は保存されます。同じコマンド（前に四分の一回転＋強斬り）をそれぞれで読むと:

| 表記 | 読み上げ |
|---|---|
| ノーマル | 下、斜め下前、前 プラス 強斬り |
| アーケード | 前に四分の一回転、強斬り |
| アーケード簡易 | 前に四分の一回転、C |
| FGC | 2 3 6、強斬り |
| FGC簡易 | 2 3 6、C |

- **ノーマル** は方向をひとつずつ言葉で言います。いちばん長く、何も前提にしません。
- **アーケード** は形の名前で言います。四分の一回転、半回転、昇龍コマンド、それぞれの逆。口頭でコマンドを伝えるときの言い方です。
- **FGC** はテンキーの数字、コミュニティの表記です。6 が前、2 が下、3 が斜め下前。常に右向きとして数えます。
- **簡易** の2種はボタン名を筐体の文字に置き換えます。A 弱斬り、B 中斬り、C 強斬り、D 蹴り。

読み上げをどう設計したか。絵は形で伝えることを、言葉は声に出して伝えなければならないからです。

- 斜めは1つの入力なので「斜め」と言います。「下、斜め下前、前」。「下、下 前、前」と言うと、入力が1つか2つか分かりません。
- くっついて描かれた2つのボタンは同時押しなので、どの表記でも「プラス」でつなぎます。
- 技名の周りに描かれる条件（「〜中」）は、二つに割らずに一度だけ言います。
- 「連打」のような条件は、それがかかるボタンの後に言います。「前 プラス 弱斬り、連打」。描かれた順ではなく、話す順です。
- ボタンと条件の名前はゲームの言葉で、ゲーム自身のコマンドリストの凡例から取っています。方向、形、「プラス」「または」はMODの言葉で、11言語分あります。
- 「または」はゲームの中でいくつかの形（2つのボタンのどちらか、2つのコマンド、一覧）で現れますが、すべて同じ言葉で言います。

リストは右スティック（上下で技ごと、左右で全部）または F2、F3、F1 で読み進めます。入ると格闘家とカテゴリー（「シキ、必殺技」）を言い、続けて各技を「技名、条件があれば条件: コマンド」の形で読みます。例:「Elysium Halo: 前、下、斜め下前 プラス 弱斬り または 中斬り または 強斬り」。

## 読み上げられるもの

- メインメニューとすべてのサブメニュー（各項目の説明つき）。
- オプション: ゲーム、画面、サウンド（音量は%）、言語と字幕、ボタンコンフィグ（各操作とそのキーまたはボタン）。
- キャラクター選択（ランダム、コスチューム、カラーを含む）、ステージ選択、対戦での操作側の割り当て。
- ストーリー: 字幕と会話、開放、エピローグ、スタッフロール。
- チュートリアル: 説明、課題、終了メッセージ（キーは言葉で）。
- コマンドリスト: 各技とそのコマンド（選んだ表記で）。スティックまたは F2 / F3 で順に読めます。
- ポーズメニューとトレーニング設定。
- データベース: プロフィール、マイランキング、総合記録。
- ギャラリー: ムービー、アートワーク、ボイス、ミュージック（タブとページを含む）。
- オンライン: リーダーボード、ランクマッチ・カジュアルマッチの画面、ゴーストマッチのゴースト一覧。
- リザルト: 勝者のセリフは自動で読まれます。スコアは保持され、スティックまたは F1 で聞けます。
- 開放のお知らせと通知。

## 読み上げられないもの

- ストーリークリア後の祝福画面は文字のない絵です。
- オンラインのルームとチャットは対戦相手ありで試していません。

## 言語

MODはゲームの言語で話します。MOD独自の言葉はスペイン語でのみ耳で確認済みで、他の言語は話者の確認なしに翻訳されています。誤った言葉は報告する価値のあるバグです。
